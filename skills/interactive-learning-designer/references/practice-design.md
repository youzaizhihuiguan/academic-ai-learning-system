# Practice, Definitions, Questions and Feedback

本文件在需要设计**定义学习、练习题、变式题、主动回忆、例/反例、提示与反馈**时读取。它不是题库模板，也不要求每次都测验；核心是根据当前学习目标选择最有信息量的任务。

## 1. 定义不是只给一句话

学习定义时，按需要选择以下动作，不必全部使用：

- **拆条件**：把对象、前提、量词、关系和结论分开，让学生指出哪个条件在起作用。
- **重建定义**：隐藏关键词，让学生从例子、图形或已知性质中恢复定义，而不是只做熟悉度判断。
- **例 / 非例 / 近失例**：给真正满足定义、明显不满足、以及只差一个关键条件的对象，帮助找到边界。
- **改条件看后果**：替换量词、去掉假设或改变约束，观察命题是否仍成立；再连接到严格定义或反例。
- **多表示对应**：把自然语言、符号、图形、表格或程序状态映射到同一概念，检查表示之间是否一致。
- **学生自己构造**：要求构造一个满足定义的对象、一个反例或一个临界例，比只识别现成答案更能暴露理解。

定义应保持学科 Tutor 的正式表述与条件；交互体验可以帮助理解，但不能为了直观而删掉关键量词或假设。

## 2. 出题先确定“想验证什么”

题目不是越多越好。先决定当前任务要观察哪种能力：

- **回忆**：能否从记忆重建定义、公式、算法步骤或判据。
- **辨析**：能否区分相似概念、条件、适用范围和常见误解。
- **执行**：能否独立计算、证明、建模、写代码或调试。
- **解释**：能否说出为什么这一步成立、为什么某个条件必要。
- **迁移**：能否把同一原理用于改变表述、数据、结构或情境后的新问题。
- **反例 / 边界**：能否主动找到结论失败的位置，而不是只套成功案例。
- **诊断**：需要定位哪一个前置概念或步骤阻塞了后续学习。

选题应服务这个能力目标，不把所有知识点机械做成选择题。

## 3. 题型是开放的

可按学科和目标自由使用或创造形式，例如：

- 开放计算、推导、证明、解释题；
- 定义填空与重新表述；
- 例 / 非例 / 近失例分类；
- 构造满足条件的对象、最小反例或边界情况；
- 证明补全、找错、修复无效步骤；
- “先预测，再观察/计算，再解释差异”；
- 多种解法或模型的比较与选择；
- 情境迁移、反事实变化、参数敏感性；
- 程序输出预测、调用栈追踪、bug 定位、最小测试设计；
- 统计设计、假设选择、结果解释与诊断；
- 把多个碎片按逻辑顺序重排；
- 基于用户提供材料生成 source-grounded 练习。

这些是例子，不构成封闭题型库。若新的交互形式更贴合学习目标，直接使用新的形式。

## 4. 难度和变式要改变“结构”，不只改数字

一组练习可以从同一能力目标产生不同层级，但不要固定成统一三档。

- **近邻变式**：保持结构，仅改变表面数据，检查是否会独立执行。
- **表征变式**：把公式改为图、语言、代码、数据或情境，检查是否认出同一结构。
- **条件变式**：增删假设、改变边界，检查能否判断方法是否仍合法。
- **迁移变式**：换到相邻但不相同的问题，检查方法选择而不是记忆答案。
- **反向任务**：给结果要求构造输入、给结论寻找条件、给错误答案定位首个失效步骤。

如果前一题失败，优先改变解释或任务粒度，而不是立刻重复同一题；如果完成顺利，再决定是否需要更远迁移。

## 5. 提示与反馈

- 提示应尽量暴露**下一步所需的关键关系**，而不是直接泄露完整答案；可以逐级增加，但用户明确要答案时必须给答案。
- 即时反馈不仅说“对/错”，还应指出关键依据、首次失效位置或为何某个选项只在额外条件下成立。
- 开放证明、统计结论、复杂程序行为或真实实验结果不能用硬编码 UI 反馈假装已经验证；应回到领域推理或真实工具。
- 记录辅助程度：示范、强提示、局部提示、无提示、迁移完成的含义不同。单次成功不能自动代表长期掌握。

## 6. 基于教材、讲义或作业出题

若题目来自用户材料：

1. 优先按真实页码、章节、原题或提供的答案定位；
2. 清楚区分**材料原题 / 原题变式 / AI 新生成题**；
3. 不编造“教材原题”“老师答案”或不存在的页码；
4. 若材料提供标准答案，先核对再作为反馈依据；若答案本身可疑，标明并让领域 Tutor 审查；
5. 可以控制覆盖范围、难度和题型，但不擅自把课程主线改造成另一套 syllabus。

## 7. 与 Evidence / Progress 的边界

练习可以产生可供领域 Tutor 审查的观察，但**出题本身不是 Evidence**。只有实际作答、真实提交、可见推理或可信工具结果才可能成为证据。

UI 内未回传的选择、看过答案、点“下一题”、自报“很懂”或一次正确都不能自动写成长期掌握。需要长期保存时，交给 `learning-progress-coordinator` 按真实来源、辅助程度和授权处理。
