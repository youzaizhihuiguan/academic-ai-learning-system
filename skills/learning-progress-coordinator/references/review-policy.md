# Retrieval, Spacing, Interleaving & Mastery

本参考在用户请求计划/复习、出现可持续追踪的薄弱环节或必须决定是否复测时才读取。它帮助长期保留，不预设统一测验格式，也不以任何单次结果给终身掌握标签。

## 当下的诊断与后续的复习不同

- 用户**尚未理解**：先由领域 Tutor 解释、补必要前置；不要要求其凭空回忆未真正学过的内容。
- 用户**刚接触并理解**：可提供轻量无提示重述或局部应用检查；若用户要继续学习，避免强制小测打断。
- 用户**已有可靠学习记录**：可在有意义延迟后安排不依赖答案提示的回忆、再推导、重做或变式，记录辅助程度。
- 用户**复测时不稳定**：缩小概念范围或补前置，再安排适当重试；不直接重复灌输同样的答案。

## 选择复测类型

- **Free recall**：不看资料说明定义、条件、关键机制、结论或算法流程。
- **Cued recall**：当完全无提示负荷过大，给最小线索；结果必须标为有提示。
- **Recognition**：选择/辨认，适用于低成本筛查或区分易混概念；不能独自支持独立证明或完整实现的结论。
- **Transfer**：相关新问题或变式，考查方法选择和迁移；验证条件依学科要求。
- **Interleaving**：概念具备基础后混合几种相关但不同的方法，促使学生辨别何时用哪一种；对先修不足者先分块教学。

## 安排与调整

优先顺序基于：学习目标重要性 → 当前证据薄弱/错误模式 → 对后续知识的依赖 → 距离上次可靠复测的时间 → 考试或项目 deadline → 用户可用时间。必要时设复测日期，但这是启发式，不是保证最优的科学常数；不要固定为每个知识点的 1/3/7 天，也不虚构 FSRS 的记忆稳定性参数。

表现更稳定时可延长复习间隔；延迟复测仍失败则缩短间隔或返回必要前置。单次全对只支持本次题目和条件；长期保持需要后续观察。

## 考试资料分支

当真实存在考试、讲义、作业或往年题时，先定位原始出处、题干和答案来源。注明：课程原文、AI 补充说明、AI 自生成练习、尚无可靠答案。针对错误再提出复习；不能把未经核对的 AI 解答写成教师标准答案。

## 与 UI 交接

UI 可降低练习摩擦，但点击次数、未回传的本地输入、自动显示正确答案都不等于真实独立回忆。只有真实可见的输出加上经领域标准检验的 Evidence，才进入持久 Review/Progress。
