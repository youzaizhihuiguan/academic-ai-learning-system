# 提示词体系使用手册 v5.4.3 同步版

本手册用于说明当前学习提示词体系如何配合使用。它不是长期路线本体，也不是阶段任务模板，而是用来帮助我判断：现在应该看哪个文件、生成什么提示词、如何继续当前阶段、什么时候更新学习记录和个人复盘说明手册。

当前稳定版本为：

```text
学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md
单阶段提示词生成器模板 v2.3.1.md
阶段内具体学习任务生成器模板 v1.3.md
```

---

## 一、当前文件体系

当前体系分为三份执行文件和两份说明 / 复盘文件。

### 1. 长期总路线文件

文件：`学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md`

作用：长期路线总控。

负责：

- 明确长期方向；
- 管理 Pxx 阶段体系；
- 区分主线任务、阶段内嵌支线和后期可选模块；
- 规定防浅学习、阶段闸门、输出证据和个人复盘要求；
- 防止路线跑偏成纯计算机科班路线、传统统计复习路线、纯前端路线或过早大模型工具路线。

不负责：

- 每次都重新生成 1 到 2 周任务；
- 替代单阶段提示词；
- 替代阶段内任务安排；
- 替代个人复盘说明手册。

### 2. 单阶段提示词生成器模板

文件：`单阶段提示词生成器模板 v2.3.1.md`

作用：生成某个 Pxx 阶段的单阶段专用提示词。

负责：

- 判断是否适合进入某个 Pxx 阶段；
- 生成该阶段的阶段导航提示词；
- 明确阶段定位、目标、边界、必学内容、技术栈、项目任务、推荐资源、输出证据和完成标准；
- 判断该 Pxx 阶段是否包含阶段内嵌支线；
- 说明该阶段可以多轮推进，也可以跨多个对话推进。

不负责：

- 把整个阶段拆成每日计划；
- 直接安排完整阶段所有任务；
- 替代阶段内具体任务模板；
- 临时扩大总路线没有允许的阶段范围。

### 3. 阶段内具体学习任务生成器模板

文件：`阶段内具体学习任务生成器模板 v1.3.md`

作用：在当前 Pxx 阶段尚未完成时，生成下一轮 1 到 2 周具体任务。

负责：

- 基于当前 Pxx 单阶段提示词和最新学习文件夹记录，安排下一轮任务；
- 判断本轮属于补缺型、推进型、项目型还是收尾型；
- 给出 1 到 3 个具体任务；
- 判断本轮是否推进当前阶段内嵌支线；
- 推荐最多 3 个资源，但资源类型要完整；
- 提醒更新学习文件夹记录和个人复盘说明手册。

不负责：

- 重新生成长期路线；
- 重新生成整个单阶段提示词；
- 把不属于当前 Pxx 阶段的支线直接塞进本轮任务；
- 跳过阶段完成标准直接进入下一阶段。

### 4. 提示词体系使用手册

文件：`提示词体系使用手册_v5.4.3_同步版.md`

作用：说明这套文件怎么使用，也就是当前文件。

负责：

- 说明各文件职责；
- 说明推荐工作流；
- 给出常用复制请求；
- 防止长期路线、单阶段提示词和阶段内任务模板混用。

### 5. 学习路线个人复盘说明手册

建议文件：`学习路线个人复盘说明手册.md`

作用：给我自己看的复盘文件，不是给 AI 执行的提示词。

负责：

- 检查每个 Pxx 阶段是否完成；
- 检查阶段内嵌支线是否该推进、已推进或暂缓；
- 检查输出证据是否真实存在；
- 检查是否浅学；
- 记录是否可以进入下一阶段。

## 二、核心工作流

当前工作流不是“一阶段等于一轮”，也不是“一阶段只能在一个对话完成”。

正确关系是：

```text
一个 Pxx 阶段
→ 可以包含多轮阶段内任务
→ 可以根据上下文长度、学习难度和对话是否发散，跨多个对话推进
→ 每轮结束都要输出学习文件夹记录
→ 阶段完成后才进入下一 Pxx 阶段
```

三个概念要分清：

```text
阶段：Pxx 阶段，是一个相对完整的学习单元。
轮次：阶段内部的一次 1 到 2 周任务安排。
对话：承载某一轮或若干轮学习的上下文容器。
```

## 三、什么时候用哪个文件

### 1. 想校准长期方向时

使用：`学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md`

适合场景：

- 不知道当前处于哪个 Pxx 阶段；
- 怀疑路线跑偏；
- 想判断某个技术是否应该现在学；
- 想确认主线、阶段内嵌支线和后期可选模块的关系；
- 想检查当前阶段是否满足阶段闸门；
- 想确认是否过早进入前端框架、工程化、大模型、Agent 或部署。

不要用它来反复生成下一轮具体任务。

### 2. 准备进入一个新 Pxx 阶段时

使用：`单阶段提示词生成器模板 v2.3.1.md`

使用条件：

- 已有长期总路线；
- 有最新学习文件夹记录；
- 想进入某个 Pxx 阶段，或需要 AI 判断当前适合哪个 Pxx 阶段。

输出结果：

- 当前阶段判断；
- 是否适合进入该 Pxx 阶段；
- 标准轻量版单阶段专用提示词；
- 本阶段目标、项目、资源、阶段内嵌支线、输出证据、完成标准；
- 学完一轮后如何继续。

注意：

- 单阶段提示词服务完整 Pxx 阶段；
- 一个 Pxx 阶段可以多轮推进；
- 一个 Pxx 阶段可以跨多个对话推进；
- 单阶段提示词不是 1 到 2 周任务表。

### 3. 当前 Pxx 阶段学了一轮，还没完成时

使用：`阶段内具体学习任务生成器模板 v1.3.md`

适合场景：

- 已经完成一轮学习或项目推进；
- 有新的学习文件夹记录；
- 当前 Pxx 阶段还没有达到完成标准；
- 需要安排下一轮 1 到 2 周任务；
- 需要判断本轮是否推进当前阶段内嵌支线。

此时不要重新生成长期路线，也不要重新生成整个 Pxx 单阶段提示词。

### 4. 当前 Pxx 阶段完成时

使用：`单阶段提示词生成器模板 v2.3.1.md`

用途：生成下一 Pxx 阶段的单阶段专用提示词。

前提：

- 当前阶段学习文件夹记录显示已达到完成标准；
- 当前阶段输出证据完整；
- 当前阶段内嵌支线状态已记录；
- 个人复盘说明手册已更新。

## 四、推荐执行顺序

### 第一步：长期路线校准

打开或粘贴：

```text
学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md
```

确认：

- 当前主线仍是应用统计背景下的数据科学、大数据、AI 工程与 AI 全栈转码能力建设；
- 长期参考仍是 FDU 应用统计人工智能方向；
- 统计背景仍作为数据理解、指标设计、模型评估、实验设计、LLM eval 和科研复现中的专业底色；
- 当前没有过早偏向前端框架、大模型工具、Agent、部署或纯考研复习。

### 第二步：生成 Pxx 单阶段提示词

使用：

```text
单阶段提示词生成器模板 v2.3.1.md
```

输入：

- 长期路线文件；
- 最新学习文件夹记录；
- 想进入的 Pxx 阶段；
- 当前补充说明。

输出：

- Pxx 单阶段专用提示词；
- 本阶段目标、边界、项目、资源、输出证据和完成标准；
- 本阶段内嵌支线状态；
- 后续轮次推进方式。

### 第三步：进入当前 Pxx 阶段学习

在当前对话或新的阶段对话中粘贴：

1. 长期路线文件；
2. 当前 Pxx 单阶段专用提示词；
3. 最新学习文件夹记录。

然后让 AI 只指导当前 Pxx 阶段。

注意：

```text
一个 Pxx 阶段可以多轮推进。
如果当前对话太长、太发散或上下文混乱，可以新开同一 Pxx 阶段的后续对话。
新对话必须粘贴最新学习文件夹记录，避免重复已经完成的内容。
```

### 第四步：每轮学习结束后输出记录

每轮学习、项目推进、补缺或阶段复盘后，都要输出：

```text
学习文件夹记录
```

学习文件夹记录至少应包含：

- 当前 Pxx 阶段；
- 本轮完成内容；
- 本轮输出证据；
- 项目进度；
- 当前阶段内嵌支线状态；
- 遇到的问题；
- 下一步建议；
- 是否可以进入下一阶段。

同时更新：

```text
学习路线个人复盘说明手册.md
```

### 第五步：生成下一轮阶段内任务

如果当前 Pxx 阶段还没完成，使用：

```text
阶段内具体学习任务生成器模板 v1.3.md
```

让 AI 基于：

- 当前 Pxx 单阶段提示词；
- 最新学习文件夹记录；
- 本轮完成情况；
- 当前问题；
- 可投入时间；

生成：

```text
本阶段下一轮学习任务安排
```

要求：

- 只安排接下来 1 到 2 周；
- 最多给出 1 到 3 个具体任务；
- 推荐资源最多 3 个，但类型要完整；
- 判断本轮是否推进当前阶段内嵌支线；
- 明确输出证据和完成标准；
- 明确学完后怎么继续。

### 第六步：阶段完成后再进入下一 Pxx 阶段

只有当学习记录显示已经达到当前 Pxx 阶段完成标准时，才使用：

```text
单阶段提示词生成器模板 v2.3.1.md
```

生成下一 Pxx 阶段的单阶段提示词。

## 五、阶段内嵌支线的使用规则

当前体系不再使用旧规则：

```text
每轮最多激活 0 到 2 条支线
```

现在使用：

```text
阶段层面决定支线归属；
轮次层面决定本轮是否推进支线；
不使用轮次层面的支线数量限制。
```

解释：

- 某条支线是否属于当前 Pxx 阶段，由长期总路线和单阶段提示词决定；
- 某一轮是否推进这条支线，由阶段内任务模板根据当前学习记录判断；
- 如果支线不服务当前阶段输出物，就暂缓；
- 如果发现当前 Pxx 单阶段提示词漏掉了必要支线，不要直接塞进本轮任务，应先生成“当前 Pxx 单阶段提示词补丁”。

记录方式统一为：

```text
当前阶段内嵌支线状态：
- 本阶段包含的支线：
- 本轮是否推进支线：
- 推进原因：
- 暂缓支线：
- 暂缓原因：
```

## 六、最常用的复制请求

### 1. 生成 Pxx 单阶段提示词

```text
请根据《学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md》、我的最新学习文件夹记录和我想进入的 Pxx 阶段，使用《单阶段提示词生成器模板 v2.3.1.md》，为我生成一个标准轻量版 Pxx 单阶段专用提示词。

要求：
- 先判断我是否适合进入该 Pxx 阶段；
- 单阶段提示词服务完整 Pxx 阶段；
- 明确一个 Pxx 阶段可以包含多轮任务，也可以跨多个对话推进；
- 不要一次性展开整个阶段的每日任务；
- 明确本阶段内嵌支线状态；
- 明确本阶段暂缓内容；
- 必须包含推荐资源配置；
- 必须说明学完一轮后如何继续；
- 必须提醒更新学习文件夹记录和个人复盘说明手册。
```

### 2. 生成当前 Pxx 阶段下一轮任务

```text
请基于当前 Pxx 单阶段提示词和我的最新学习文件夹记录，使用《阶段内具体学习任务生成器模板 v1.3.md》，为我生成“本阶段下一轮学习任务安排”。

要求：
- 不重新生成长期路线；
- 不重新生成整个 Pxx 单阶段提示词；
- 只服务当前 Pxx 阶段；
- 只安排接下来 1 到 2 周；
- 最多给出 1 到 3 个具体任务；
- 判断本轮是否推进当前阶段内嵌支线；
- 推荐资源最多 3 个，但类型要完整；
- 明确本轮目标、任务类型、学习节奏、项目推进、暂缓内容、完成标准和学完后怎么继续；
- 提醒更新学习文件夹记录和个人复盘说明手册。
```

### 3. 判断是否可以进入下一 Pxx 阶段

```text
请根据我的最新学习文件夹记录，判断我是否已经达到当前 Pxx 阶段完成标准。

如果还没有达到，请不要让我进入下一阶段，而是建议使用《阶段内具体学习任务生成器模板 v1.3.md》生成下一轮任务。

如果已经达到，请提醒我可以使用《单阶段提示词生成器模板 v2.3.1.md》生成下一 Pxx 阶段单阶段提示词。

请同时检查：
- 输出证据是否完整；
- 当前阶段内嵌支线状态是否已记录；
- 个人复盘说明手册是否需要更新。
```

### 4. 当前 Pxx 单阶段提示词补丁

```text
我怀疑当前 Pxx 单阶段提示词漏掉了某个必要支线或必要边界。
请不要直接重写整个单阶段提示词。
请基于《学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md》和当前 Pxx 单阶段提示词，判断是否需要生成“当前 Pxx 单阶段提示词补丁”。

要求：
- 只判断这个支线是否确实属于当前 Pxx 阶段；
- 如果属于，说明它服务哪个阶段输出物；
- 如果不属于，说明应暂缓到哪个 Pxx 阶段；
- 不要扩大当前阶段范围；
- 不要重新生成整个单阶段提示词。
```

## 七、不要混用的情况

### 1. 不要每次学完都重开长期路线

学完一轮后，优先判断当前 Pxx 阶段是否完成。

```text
没完成：使用阶段内具体学习任务生成器模板 v1.3。
完成了：使用单阶段提示词生成器模板 v2.3.1 生成下一 Pxx 阶段提示词。
跑偏了：回到长期总路线 v5.4.3 校准。
```

### 2. 不要把单阶段提示词写成每日计划

单阶段提示词是阶段导航，不是周计划。

它应该说明：

- 当前 Pxx 阶段学什么；
- 为什么现在学；
- 学到什么程度；
- 做什么项目；
- 本阶段有哪些内嵌支线；
- 什么暂缓；
- 怎么判断完成。

具体 1 到 2 周任务交给阶段内具体学习任务模板。

### 3. 不要让阶段内任务模板替代单阶段提示词

阶段内任务模板只安排下一轮任务。

它不能替代：

- 阶段定位；
- 阶段目标；
- 阶段完成标准；
- 长期路线判断；
- 阶段内嵌支线归属判断。

如果发现单阶段提示词本身有缺漏，应生成“当前 Pxx 单阶段提示词补丁”，不要让阶段内任务模板硬塞新内容。

### 4. 不要把个人复盘说明手册当成 AI 执行模板

个人复盘说明手册是给我自己看的，不是给 AI 直接执行的任务模板。

它用于检查：

- 我是否真的完成了当前阶段；
- 是否留下输出证据；
- 是否浅学；
- 支线是否推进或暂缓；
- 是否可以进入下一阶段。

## 八、判断当前该做什么

可以按下面规则判断：

- **不知道长期方向是否合理**：看 `学习路线v5.4.3_AI全栈防浅学习执行版_阶段多轮与内嵌支线修正版.md`。
- **准备进入新 Pxx 阶段**：用 `单阶段提示词生成器模板 v2.3.1.md`。
- **当前 Pxx 阶段学了一部分，还没完成**：用 `阶段内具体学习任务生成器模板 v1.3.md`。
- **不知道是否能进入下一 Pxx 阶段**：先检查学习文件夹记录和阶段完成标准。
- **怀疑当前 Pxx 单阶段提示词漏了必要支线**：生成“当前 Pxx 单阶段提示词补丁”。
- **任务太多、太散、太远**：回到阶段内任务模板，只安排下一轮 1 到 2 周。
- **阶段完成或月度复盘**：同步更新学习文件夹记录和个人复盘说明手册。

## 九、核心原则

记住这句话：

```text
长期路线负责方向校准、阶段顺序、阶段内嵌支线归属、深度控制和防跑偏；
单阶段提示词负责 Pxx 阶段导航；
阶段内具体学习任务负责当前 Pxx 阶段下一轮 1 到 2 周执行安排；
学习文件夹记录负责跨轮次连续性；
个人复盘说明手册负责人工验收和长期复查。
```

推荐执行链路是：

```text
长期路线校准
```
